# Legacy Java Monolith → Reactive Vert.x

Research and reproducibility repository for:

**Performance and Cost Optimization in Enterprise Systems: A Quantitative Analysis of Migrating Legacy Java Monoliths to Reactive Vert.x Architectures**

## Repository

```
├── paper/                 # IEEE manuscript and submission assets
├── research/              # methodology and mathematical model
├── implementation/
│   ├── legacy-monolith/   # blocking Spring/Tomcat reference
│   └── reactive-vertx/    # non-blocking Vert.x reference
├── benchmark/             # k6 workload
├── benchmark-results/     # manuscript-reported values and future runs
├── diagrams/              # architecture diagrams
└── docs/                  # reproducibility protocol
```

## Architecture

```text
Load Generator
      │
      ├──────────────► Blocking Java Monolith
      │                 worker thread
      │                 blocking wait
      │
      └──────────────► Reactive Vert.x
                        event loop
                        async wait
```

## Run

Prerequisites: Java 21+, Maven 3.9+, Docker, k6.

```bash
docker compose up --build
BASE_URL=http://localhost:8080 k6 run benchmark/k6-concurrency.js
BASE_URL=http://localhost:8081 k6 run benchmark/k6-concurrency.js
```

## Benchmark integrity

The values in `benchmark-results/paper-reported-results.md` are **reported by the manuscript**, not newly generated by this repository. They are retained as a reference baseline. New IEEE evidence must come from a documented reproducible run with raw measurements, environment metadata, and the exact git commit.

See `docs/reproducibility.md` and `benchmark/README.md`.

## Research scope

The paper studies blocking versus event-driven execution, Little's Law, the Vert.x Multi-Reactor model, throughput, latency, context switching, memory footprint, cloud OpEx, and future AI-assisted refactoring.
